# Secure Vision Grid Solutions — GitHub Pages

This folder is ready to upload directly to a GitHub repository for GitHub Pages.

## Files
- `index.html` — main website
- `404.html` — GitHub Pages fallback page
- `images/` — all website images

## Deploy
1. Create a GitHub repository (for example: `secure-vision-grid`).
2. Upload the **contents of this folder** so `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/secure-vision-grid/`.

Do not upload the ZIP file itself if you want GitHub Pages to publish the website; extract it first and upload `index.html` plus the `images` folder.
