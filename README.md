# Secure Vision Grid Solutions — Premium Website

GitHub Pages-ready website using the supplied logo, CCTV, networking, biometric, intercom and services-poster images.

## Publish
1. Create a GitHub repository, e.g. `secure-vision-grid`.
2. Upload `index.html` and the `images` folder.
3. GitHub → Settings → Pages.
4. Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
